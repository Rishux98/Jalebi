## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- npm or yarn
- <!-- TODO: database or other services -->

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd hackinno
   ```

2. Install backend dependencies and start the server:

   ```bash
   cd server
   npm install
   npm run dev
   ```

3. In a new terminal, install frontend dependencies and start the client:

   ```bash
   cd client
   npm install
   npm run dev
   ```
